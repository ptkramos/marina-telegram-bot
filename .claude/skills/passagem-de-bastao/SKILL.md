# Passagem de bastão

O Patrick tende a fazer tudo numa conversa só; conversas longas perdem detalhe quando são resumidas. Cabe a você
avisar a hora de trocar e deixar a próxima conversa pronta pra começar sem reler tudo.

## Passos
1. **Feche o que está aberto:** testes verdes, commit com os três relatórios atualizados no mesmo lote, deploy
   (respeitando a regra do reinício). Se algo ficou pela metade, diga exatamente o quê.
2. **Atualize `FRENTES_MARINA.md`:** mova o que ficou pronto para "Pronto", reordene o "Próximo" e ajuste a data
   no topo. Uma linha por item; detalhe fica nos planos.
3. **Memória:** se surgiu regra nova do Patrick sobre como trabalhar, salve (sem duplicar).
4. **Commit** do painel (`FRENTES_MARINA.md`) se mudou.
5. **Responda ao Patrick, curto:**
   - o que ficou pronto (2–4 linhas);
   - a frente e o item da próxima conversa;
   - a **frase de abertura** pronta pra ele colar numa conversa nova (a mesma do painel, ajustada ao item).
